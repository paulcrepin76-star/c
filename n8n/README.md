# n8n for Survey Cafe

You do **not** add Square, Mealie, or Paperless credentials in n8n.

1. Open http://100.116.48.120:8088/connect
2. Click **Connect** on Square, Mealie, and Paperless. Log in there with the accounts you already use.
3. Optionally click **Sync now** on that same page.

n8n only runs at night and tells the cellar to pull sales, recipes, and invoices. The logins never sit in n8n.
