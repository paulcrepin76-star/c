Connect Square, Mealie and Paperless

The workflows are already in n8n. Open n8n, add three credentials, then turn the workflows on. Do not paste those tokens here.

  1. Open n8n — http://100.116.48.120:5678 Log in with the Survey Cafe owner account you already created.
  2. Credentials → Add credential → Header Auth Create these three names exactly:
    • Square Access Token — Header name Authorization, value Bearer YOUR_SQUARE_TOKEN
    • Mealie API — Header name Authorization, value Bearer YOUR_MEALIE_TOKEN
    • Paperless Token — Header name Authorization, value Token YOUR_PAPERLESS_TOKEN
  3. Open workflow “Square sales → cellar” Click the red node “Square settings”. Put your Square Location ID there. Save. Toggle Active.
  4. Activate “Mealie recipes → cellar” and “Paperless invoices → cellar”.
  5. Click Test workflow on “Check cellar connection”. It should say resto-core is ok.

Where to get the tokens

Square: Developer Dashboard → Applications → Production → Access token, and Locations for the Location ID.

Mealie: your Mealie user menu → API tokens → generate.

Paperless: Paperless → your user → API tokens → generate. Paperless is at port 8011.
