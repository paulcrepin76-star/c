1 · Chrome extension (Sam’s, Costco, Chef’s, Gordon)

Install Restaurant Price Collector in Chrome on the Mac you already shop from:

  1. Open chrome://extensions
  2. Turn on Developer mode
  3. Load unpacked → /mnt/user/appdata/resto/apps/resto-core/app/static/extension on Unraid, or copy the extension folder from this site
  4. Open the extension options. Cellar URL must be {{ cellar_url }} (port 8088, not n8n on 5678).
  5. Paste this cellar key — not an n8n API key:

    {{ cellar_api_key }}

  6. Click Test connection in the extension. Then log in to Sam’s or Chef’s and click Send visible prices.

The extension only sends what you can already see. Session cookies stay in Chrome. Treat the API key like a password.

2 · Official APIs (no login)

Open Prices (crowdsourced, geo-filtered) and the US retail average (BLS) run with the nightly scan. USDA MyMarketNews wholesale waits on USDA_MMN_API_KEY. Instacart waits on their 30–40 day developer approval — the collector row is already there.

3 · Full browser for public JS (Publix, Target, Aldi)

Those sites hide dollars until JavaScript runs. Playwright Chromium can render them without logging in. This cellar image does not bundle Chromium (it is huge). Use the extension today, or add a collector Compose profile later with the official Playwright image. We still will not fight PerimeterX on Sam’s or Costco that way.

4 · Receipts

Paperless OCR remains the highest-confidence price. After Costco, drop the PDF or photograph the receipt. That pack is what you actually paid.
